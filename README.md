# NeoBookMarkManager（Bookmark Studio）

ブラウザのブックマークを読み込んで、整理・統合するデスクトップアプリです。
Chrome・Edge・Firefox から書き出したブックマークの HTML ファイルを扱います。

**最新版: v2.0.0**（2026-01-20）

## できること

- ブックマークを、フォルダの木の形（ツリー）で表示・編集します。
  - ドラッグ＆ドロップで、移動や並べ替えができます。
  - 2つのツリーを左右に並べる「2画面モード」で、整理しやすくなります。
  - 表示を Tree・List・Card で切り替えられます。
- 整理の機能
  - フォルダの中の重複したブックマークを消します。
  - 同じ名前のフォルダを1つにまとめます。
  - タイトル順・ドメイン（サイトのアドレス）順に並べ替えます。
  - アドレスしか出ていないブックマークに、サイトからタイトルを取ってきて付けます。
- 分類の機能
  - サイトのアドレスごとに、自動でフォルダ分けします。
  - AI（Gemini）で、タイトルとアドレスから分類先を考えさせることもできます。
  - タグを付けて、タグで探せます。
- 検索欄で、すぐに目的のブックマークを探せます。
- ファビコン（サイトの小さなアイコン）を表示します。
- 社内ネットワーク向けに、プロキシの設定と接続テストができます。

## インストール

1. Python 3.10 以上を入れます。
2. このフォルダで、仮想環境（フォルダ専用の Python 環境）を作って有効にします。
3. 必要なライブラリを入れます。

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

> 補足: Linux・macOS では `scripts/run.sh` で、準備から起動までまとめて行えます。

### AI 分類を使う場合

1. `config/config.ini.example` をコピーして、`config/config.ini` を作ります。
2. `[API]` の `api_key` に、Google AI の API キー（AI を使うための鍵）を入れます。
   - 環境変数 `GENAI_API_KEY` か `GOOGLE_API_KEY` があれば、そちらが優先されます。
3. 社内ネットワークで使うときは、`[Proxy]` にプロキシの情報を入れます。

## 使い方

1. `python main.py` で起動します。
2. 「Open HTML」で、ブラウザから書き出したブックマークの HTML を開きます。
3. ツリーで、ブックマークを移動・編集します。
4. 右側の操作パネルで、「🧹 整理」や「✨ AI分類」の機能を使います。
5. 「Save」か「Save As」で、HTML として保存します。
6. 保存した HTML を、ブラウザに読み込み直します。

> ⚠️ 整理を始める前に、元のブックマークの HTML を必ず控えておいてください。

## フォルダ構成（開発者向け）

```
├─ main.py            起動用
├─ core/              データの形・保存・バックアップ・フォント
├─ gui/               画面（controllers/ に操作の処理）
├─ services/          整理・分類・検索・タグ・通信の処理
├─ config/            設定（app_config.py に版、config.ini.example、prompt.txt）
├─ tests/             自動テスト（pytest）
├─ scripts/           起動・準備用のスクリプト
├─ samples/           試し用のブックマーク HTML
└─ .docs/             インストール・フォントなどの詳しい説明
```

```
pytest tests --ignore=tests/manual
```

> 補足: 版を上げるときは、`config/app_config.py` の `VERSION` と、`gui/UtilGuiResources.py` の `APP_VERSION` をそろえて書き換えます。

## プライバシー

- ブックマークは、このパソコンの中で扱います。
- 「AI分類」を使うと、ブックマークのタイトルとアドレスが Google の AI に送られます。
- 「タイトルの取得」やファビコンの表示では、各サイトにアクセスします。
